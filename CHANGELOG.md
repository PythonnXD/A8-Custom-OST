# Changelog

## v1.3.0

### Highlights
- **Redesigned App Updates**: Streamlined update dialog with automatic release checking, single Close action, and no exposed API URL or local package controls.
- **Structured Release Changelog**: Formatted highlights and release metadata (`Published` date and package size) directly inside the App Updates dialog.
- **Portable `.zip` Release Packaging**: Standardized automated releases on `A8_Custom_OST_Patcher-win64.zip` and fixed asset resolution against the public GitHub Release feed.

## v1.2.0

### Highlights
- **Desktop Interface & Themes**: Dark and Light modes, Asphalt 8 branding, drag-and-drop import queue, and flexible file, folder, or `.zip` scanning.
- **Outro Song Editor & Waveform**: Interactive 120-bin PCM waveform canvas with draggable trim bounds, fade-in/out controls, and live clip playback.
- **Station & Metadata Tools**: Batch artist and station assignment, inline Song Title/Artist/Station editing in Queue and In-Game Library, plus Peak/RMS loudness badges.
- **Health Check, Profiles & Export**: Soundpack Health Check & Orphan Cleaner, named MOD Profiles (loadouts), portable `.zip` Mod Pack export, and timestamped backup restore.
- **Windows Permission Helper**: Scoped ACL/Read-Only fix for `Data/soundpack`, `Data/music`, `Data/text`, plus **Make writable copy** fallback for protected Microsoft Store folders.
- **Keyboard Shortcuts & Updates**: Full keyboard navigation (`?`) and one-click in-app update check and installation.
